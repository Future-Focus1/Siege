# SIEGE

Portrait physics siege game for Godot 4.7.2.

Open the project in Godot 4.7.2 and press Play. The main menu starts a quick battle: drag backward from the catapult to aim and set power, then release. Reset rebuilds the tower.

Headless checks:

```
godot --headless --path . res://tests/test_runner.tscn
```

Design notes live in `docs/`.
